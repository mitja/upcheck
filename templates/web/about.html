{% translate "About UpCheck" %}

{% blocktranslate trimmed %} UpCheck is a lightweight uptime monitor for websites and APIs. You add the addresses you care about, choose how often they should be checked (every 1 to 60 minutes), and UpCheck pings them on schedule, charts their response times, and can publish a public status page for each monitor. {% endblocktranslate %}

{% translate "Who runs it" %}

{% blocktranslate trimmed %} UpCheck is an independent product built and operated by Mitja Martini — no company, no sales team, just a working service. You can reach me anytime at mitja.martini@gmail.com. {% endblocktranslate %}

{% translate "Open source, on purpose" %}

{% blocktranslate trimmed %} UpCheck doubles as a public, open-source demo of running a Django SaaS in production. It is built on the open-source SaaS Pegasus boilerplate, handles subscriptions through Polar.sh via the django-polar-sh package, and runs on PAASBOX, managed Kubernetes on Hetzner. The complete source code — including the deployment manifests for this very instance — is on GitHub. {% endblocktranslate %}
